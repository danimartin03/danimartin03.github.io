Editor de Markdown

Un editor de Markdown con vista previa en vivo: escribes a un lado y al otro ves el documento ya con formato. No tiene servidor: el texto se guarda en el navegador.

Qué hace

  • Vista previa en vivo en dos paneles, que en el móvil pasan a ser dos pestañas.
  • Barra de herramientas y atajos para negrita, cursiva, título, lista, enlace, código y cita.
  • Contador de palabras, caracteres y tiempo de lectura, y autoguardado.
  • Abrir un archivo .md y descargar el .md o una página HTML completa.
  • Colores en los bloques de código y tema claro y oscuro.

Cómo funciona

Markdown permite escribir HTML dentro del texto. Si lo mostrara tal cual, un documento abierto desde un archivo podría ejecutar código en la página (un ataque XSS).

Por eso todo el HTML pasa por DOMPurify antes de llegar a la pantalla. Hay una sola función que convierte y limpia, y un solo sitio donde entra HTML en la página, para que no se pueda saltar por descuido. Lo probé con una lista de ataques conocidos.

Está hecho con HTML, CSS y JavaScript sin frameworks. Usa tres librerías por CDN (marked, DOMPurify y highlight.js) con versión fija y comprobación de integridad.

Lo que aprendí

  • Qué es un ataque XSS y por qué no se puede mostrar HTML que viene de fuera sin limpiarlo.
  • Trabajar con la selección de un campo de texto sin romper el deshacer (Ctrl+Z).
  • Probar las funciones con muchos casos al azar: así salieron dos fallos que a mano no había visto.
